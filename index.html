从教务到桌面，三步

不需要注册账号，装好就能用。导入读的是你自己学校的教务页面，读不到也还有 CSV 这条退路。

把课表搬进来

内置 WebView 登录正方教务，进到「个人课表查询」再点读取；没有教务账号也能按模板填 CSV，UTF-8 / GBK 都认。

校准这一学期

设开学日期和总周数，单双周、连堂、每天的节次时间都会自己算；周几是第一天、要不要显示周末，也能改。

挂到桌面上

小组件有 2×2、4×2、4×4 和「今日 · 明日」四种尺寸；在应用里点一下就能请求添加到桌面。

它实际能做的事

下面每一条都对应工程里已经实现的界面与逻辑，没有“即将上线”。

今日 / 周课表

两套视图看同一份数据。周课表按节次排布，单双周与连堂会正确合并；今日页只留今天，已上过的课自动划掉。

单 / 双周自定义节次时间隐藏周末非本周课程淡化

多套课表

一个学期一套，互不干扰：课程、节次、开学日期、总周数和配色都可以单独设，切换时不用重新导入。

新建 / 重命名独立配色独立节次独立学期

教务系统导入

应用内打开 WebView 登录正方教务，读取 kbList 返回的课表；也可以按模板批量粘贴 CSV，周数支持 1-8、10-16 这类混搭写法。

正方 zftalCSV / GBK预览后再确认

学习通作业与考试

登录后拉取作业和考试两个列表，带剩余时间与状态标记。账号密码不保存，Cookie 只在本机应用私有目录里，可以随时退出清掉。

作业 / 考试分栏剩余时间本地 Cookie

成绩与本学期汇总

从教务读取成绩，按学年 / 学期分页；顶部给出加权平均分、总学分、平均绩点，往下是科目、学分、绩点与考核成绩。

加权平均分平均绩点多学期切换

上课前提醒

按当天的课排精确闹钟，提前 5 / 10 / 15 / 30 分钟可选。一次只排未来 7 天，响过之后自动重排，长期只占几十个闹钟。

精确闹钟4 档提前量7 天滚动

调课 / 停课 / 临时加课

只改某一天，不动整学期：把课挪到另一天、临时停一节，或者加一门只上几周的课，都能在课表格子里直接操作。

按日期生效单双周加课可删除记录

课程待办

每门课下可以挂一条计划，比如「周四交实验报告」；勾掉后记录仍保留，复习这门课时能看到自己做过什么。

按课程归类完成记录可关闭

六套配色，玻璃是活的

下面可以真的点。配色、深浅、卡片透明度都是应用里的设置项，不是截图。

深浅色默认跟随系统，也可以手动锁定。切换时整套配色会逐帧插值，不会先闪一下再变；配色只换强调色，课程色、错误色这些语义色保持不变。

液态玻璃打开后，底部导航栏用 Haze 做真模糊加 AGSL 边缘折射；卡片单独采样壁纸，避免把别的卡片和文字一起糊进去。关掉就退回普通磨砂，滑块仍然可调。

数据只在你的手机里

没有账号体系，也就没有“账户数据”。这是这个项目最想认真说清楚的一件事。

  • 不需要注册没有登录、没有手机号、不接入任何统计 SDK，应用不收集个人信息。
  • 没有自有服务器课表、课程、调课记录、待办、成绩和设置，全部写在应用私有目录的 data.json 里。
  • 学习通密码不保存账号密码只在 WebView 的页面里提交；Cookie 留在本机，退出登录即可清掉。
  • 备份自己拿设置里可以把全部数据导出成一个 JSON，换手机时再导入；导入会覆盖当前数据，应用会先提示。
  • 代码可查Apache-2.0 开源，不放心可以直接读源码，或者自己构建一个装。

导出备份 = 一个 JSON 文件

▣ 课表备份_20261117.json 1 个文件
课表课程调课 / 停课记录课程待办成绩设置

文件内容随版本变化，这里只说明它包含哪些数据；具体字段以实际导出为准。文件由你自己保存，应用不会上传。

它不是什么

写清楚边界，比堆功能更有用。

  • 不是学校官方应用
  • 不保证所有教务系统都能导入
  • 不替代学习通或教务系统
  • 没有云同步与多端同步
  • 没有 iOS 版
  • 不做成绩预测或绩点规划

教务和学习通的页面结构随时可能变，导入失败是正常情况。这个应用做的是「把已经能拿到的数据整理好」，而不是替你绕过学校的系统。

常见问题

答案尽量具体，不确定的地方也写出来。

教务导入读不到课表怎么办？

先确认学校用的是正方教务的 kbList 接口体系，并且在 WebView 里已经进到「个人课表查询」页面再点读取。不同学校的页面路径和参数不完全一样，没适配到的就只能用 CSV。

CSV 每行一条安排，列顺序是「课程名称, 星期, 开始节数, 结束节数, 老师, 地点, 周数」，例如 高等数学,1,3,4,马老师,教学楼301,1-16。周数支持连续 1-16、离散 1、2、隔周 2、4、6、混搭 1-8、10-16；编码 UTF-8 或 GBK 都能识别。

学习通的账号密码会被保存或上传吗？

不会保存密码。登录发生在学习通自己的网页里，应用只是提供 WebView；登录后的 Cookie 存在本机应用私有目录，用来请求作业和考试列表，可以随时退出登录清除。

应用没有自有服务器，也没有把 Cookie 发往第三方的代码。

换手机、重装应用，数据怎么迁移？

在设置里导出备份，得到一个 JSON 文件，自己存到网盘或电脑；在新设备上导入即可。导入会覆盖当前全部数据，操作前应用会提示。

没有自动云同步，也不会在后台悄悄上传。

小组件不刷新是坏了吗？

多数情况是系统限制。应用会在课表变更、跨天、闹钟触发时请求刷新，但 Android 会限制后台更新频率；部分厂商系统还需要把应用加入电池优化白名单。

如果长时间停在旧数据，先打开一次应用，让课表状态重新计算。

需要一直联网吗？

不需要。看课表、今日课程、待办、成绩、小组件全部离线可用；只有教务导入、学习通任务和检查更新需要网络。

为什么不在应用商店里？

个人项目，没有上架计划。APK 通过 GitHub Releases 发布，安装时系统会提示「未知来源」，确认来源是 github.com/zy2755/AnonSchedule 即可。
